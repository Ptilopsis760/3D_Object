## 二、任务与要求

3d 打印工作台为一固定尺寸长方体，针对给出的多类 3d 零件数字模型，设计自动摆放算法，满足单模型优先级和数量约束的前提下，工作台的空间利用率最高，提供 UI 界面可视化和结构化导出。

### 1、项目问题描述

\(1\) **约束条件**：存在一个固定长方体封闭空间（示例尺寸 4000×2500×1500mm）；输入 \> 10 类不同外形的 STL 三维零件模型，每一类可以无限复制使用；摆放时零件之间不能发生碰撞，需要预留固定间隙 5mm；模型可以沿三轴做任意旋转、允许空间悬浮摆放，不要求物理支撑；硬性约束：同批次零件内每一类至少要摆放一个。

\(2\) **优化目标**：最大化空间利用率，不强制求解全局最优解，获得效果较好的近似解就满足要求。

\(3\) **拓展约束**：若干零件为一批 / 一组，若空间还有位置则尝试摆下第二批，若第三批不能完整摆放，则尝试摆放小零件。

## 三、拟采用的研究方案和要解决的关键技术问题

### 1、总体研究方案

本项目聚焦三维不规则模型自动摆放问题，属于三维装箱优化范畴，采用 \\*\\*“数据解析预处理 \+ 智能摆放算法 \+ 三维可视化渲染”\\*\\* 的整体技术方案，以轻量化 Demo 开发为核心，兼顾功能完整性与运行稳定性。整体流程分为三层，底层为模型数据解析层，中层为算法计算优化层，上层为可视化交互展示层。

首先，基于 OpenMesh 开源库完成 STL 三维模型文件的解析读取，提取模型顶点、面片、法线等核心几何信息，通过包围盒（Bounding‑box）算法对不规则模型进行简化处理，降低后续算法运算复杂度。其次，核心采用贪心算法作为基础摆放算法，结合项目自定义约束规则（零件间距、无碰撞、全品类摆放、分批摆放）优化算法逻辑，通过模型三轴旋转遍历、空间空位检测、碰撞检测等核心逻辑，迭代求解最优摆放方案，无需全局最优，保证摆放效果最优近似解。最后，搭建轻量化可视化 UI 界面，调用图形开源库完成三维模型渲染，实现参数配置、一键计算、结果展示、数据导出全流程功能，完成系统整体闭环。

### 2、关键技术问题

1. **不规则 STL 模型轻量化处理技术**：项目输入的 3D 零件均为非规则几何体，无标准长方体、圆柱体规整结构，直接运算复杂度极高。需解决不规则模型几何信息解析、筛选与简化问题，通过精准计算模型最小包围盒，将不规则模型空间占用问题转化为规整空间占位问题，大幅降低算法运算压力。

2. **多约束下三维空间碰撞与间距检测技术**：摆放过程需严格满足零件无碰撞、固定间距约束，同时适配模型三轴任意旋转的场景。需实现高精度三维空间碰撞检测算法，适配不同旋转角度的不规则模型，精准判断模型间、模型与边界的距离，规避模型重叠、间距不达标问题，满足项目摆放约束规则。

3. **多策略自适应摆放算法优化**：针对分批摆放、补位填充、全品类覆盖等多重约束，需优化基础贪心算法逻辑。解决优先批量摆放、剩余空间小零件补位、同批次零件全覆盖等场景适配问题，平衡摆放效率与空间利用率，输出符合项目要求的近似最优摆放结果。

4. **三维模型可视化渲染与数据映射技术**：实现 STL 模型快速渲染、摆放结果实时展示，同时建立可视化模型与算法运算数据的一一映射关系，精准还原模型旋转、平移状态，同步统计并展示空间利用率、零件数量等核心指标，支持结构化变换数据导出。
